Getting started

Introduction

NexBot is a Silkroad Online bot that runs with the game window or without it (clientless). This guide explains every page of the program, one page at a time.

The window

  • Menu (left). Every feature has its own page. Click a name to open it.
  • Page (middle). Most pages have three panels: a list on the left, settings in the middle and actions or results on the right.
  • Status bar (bottom). Shows the bot state (Idle, Running…), the mode (client or clientless), the proxy, the character and the server version.
  • State light (top right). Shows at a glance whether the bot is idle or running.

Settings are saved by themselves

Everything you change is saved right away to settings.json next to NexBot.exe. There is no Save button. Copy this file to move your settings to another PC or another NexBot folder.

The password is stored encrypted with your Windows account. A settings.json copied to another PC keeps every setting, but you have to type the password again there.

Getting started

Quick start

From a fresh download to a character in the game in five steps.

  1. Choose the Silkroad client folderOpen Server, click Browse and select the folder that contains sro_client.exe and Media.pk2.
  2. Read the server configClick Read server config. NexBot reads the version, locale, gateway port and divisions from Media.pk2 and fills Division and Gateway.
  3. Build the database (once per client)Click Build database. NexBot reads items, skills, monsters, teleports and map names from the client into Database.sqlite3. When it is done, Database shows ready and the date. Build it again only after the client is updated.
  4. Fill in Auto LoginType the username and password, then pick the Server and Character. Leave Log in automatically and Select the character automatically on.
  5. StartClick Start client to play with the game window, or Start clientless to run without it. The status bar changes from Idle, and the character appears on the Server, Character and Map pages.

Tip: start with the game window first. Once the character is in the game, click Go clientless. The window closes and the character stays online, using far less CPU and memory.

Training area: circle or polygon

The training area is where the character will fight. A circle is a center and a radius (5 to 1000). A polygon follows any shape, such as one side of a river or the area between two walls.

  1. Record polygonClick Record polygon.
  2. Click the cornersClick the corners on the map clockwise, one by one.
  3. Stop recordingClick Stop recording. A polygon needs at least 3 corners. Clear removes it, and the circle is used again.

The hunting bot (Attack page) attacks the monsters inside the training area.

World

Script

Record a route once, then let NexBot walk it again. Teleports and return scrolls are recorded too.

Recording a route

  1. Press ● RecordThen walk in the game, or click the map to walk.
  2. Walk the routeA point is added every N units walked (set A point every) and wherever the character stops. Teleporters and return scrolls you use become lines too.
  3. Add waits+ Wait 3 s adds a pause, for example in front of an NPC.
  4. Press ■ Stop, then Save…Scripts are plain text files. Open… loads one, and Clear starts over.

Walking a script

Press ▶ Start walking. NexBot starts at the script point nearest the character (or at line 1) and uses the teleports and return scrolls on the way. Turn on Loop at the end to start over when the script ends.

Script lines

World

AutoTrade

Trade runs: wear the trader suit, ride the transport, buy at the specialty trader, walk to the next town and sell, again and again.

Transport and trader suit

  • Trade transport: transports that can carry trade goods. Click one to prefer it for RIDE,TRANSPORT. Click it again to use any transport you have.
  • Trader suit: trader flags and bags this character can wear. Click one to prefer it. Otherwise any trader suit in the bag is used.
  • Transport: buttons to Wear suit, Ride transport and Get off by hand, plus the list of what the transport carries.

Trade loops

Each loop is a script from the Script page that goes from one town to the next: ride the transport, buy at the specialty trader, walk, sell. For example: Jangan → Donwhang, then Donwhang → Hotan. Loops run in list order. Use Add…, Remove, Up and Down to arrange them.

Trade goods

Pick a trader to see its goods. Tick the goods to buy and set how many. How much a buy line buys sets the amount per BUY line.

Trade options

Use return scroll after the loops completeGoes back to town when finished.

Press Start trade to begin and Stop to end.

Character

Character

Stats, details and pets, plus the skill window with automatic mastery and skill leveling.

Character, Details and Pets

Character shows the name, level, race, the active buffs as icons (skill buffs and scroll or item effects, with the time left on each icon; hover for the game's buff card: name and level, duration, effects such as Physical damage 20% Increase, and the remaining time), the HP / MP / EXP / skill EXP bars and the stats (strength, intellect, free stat points, berserk, attack, defense, hit and parry rates). Details shows gold, skill points, job, PvP cape, murders, guild, location, riding and account. Pets lists summoned pets and mounts with HP and hunger.

Skills

The middle panel looks like the in-game skill window. The up buttons learn the next skill level or raise a mastery. Hover a skill to see the next level's cost.

Auto leveling

Right-click a skill or a mastery, or use AUTO, to mark it for automatic leveling. NexBot then spends skill points by itself whenever there are enough.

Attack NEW

The hunting bot, in tabs: attack skills, buffs, party buffs, resurrect, healing, luring and the attack log. It hunts in the enabled training area.

Start bot starts hunting. In town, the town loop runs first (shopping, storage) and then walks to the training area: on the training script, or on the map's routes when there is none. Stop stops it. Train here moves the enabled training area to where the character stands. The bot waits while a walking script, the trade route or the town loop moves the character.

  3. ImbueChoose the Imbue for the type (Chinese). It is cast before the skill when it is not on.

Which monster: those attacking you, then those attacking your party, then the monster preferences, then the nearest; only inside the training area (attackers anywhere). With Collision detection (Training area), monsters behind walls are left out. A monster that takes no damage for 20 seconds, or refuses 4 attacks, is left alone for a minute. With no monster, the bot walks around inside the area (or to its middle, with Don't walk around) and picks up drops (Pick filter).

Buffs tab

A buff is cast when it is not on, it is ready and there is enough MP. Emergency buffs are cast when HP or MP is under the percentage, or more monsters attack than the number. Switch weapons for buffs puts on a fitting weapon from the bag for a buff that needs one, then the first weapon again. Use Devil's Spirit keeps the devil avatar's buff on: cast it once yourself in the game first, so the bot learns which skill your devil has (a skill the character does not have gets it disconnected, so the bot never guesses). Force Cure cures a bad status with your cure skill. Recast all buffs when one ends casts the whole list again. A refused buff is tried again after 30 seconds.

Party Buffs tab

Choose a buff, then the players to keep it on (party members or names). The bot walks to a player in the Party buffing radius, casts the buff on them and, with Walk back, goes back to the middle of the area. Buff all nearby players buffs everyone near; Start / stop if a player is near buffs only while one of the listed names is near.

Resurrect tab

Dead players of the list (or all party members) in the Resurrect radius are resurrected after the delay, with your resurrect skill (a group resurrect when several are dead), up to the try limit each. Auto accept res answers yes when another player resurrects you (optionally only party members).

Healing tab

Add your heal skills. First yourself when your HP is under Heal self, then a group heal when the average HP of you and the living members is under Group heal, then the member with the lowest HP under Heal party member. Party HP comes from the game in 10% steps.

Lure tab

For parties: one character walks out (a random way, or along a script's points), casts the skill at the edge (Howling Shout ...) and walks back, with the delays at the edge and the center. Luring stops while too many party members are dead, too many party giants / champions or monsters are in the area, or party members are away. Turn on Don't attack monsters to only lure.

Attack Log tab

Every player who attacked or killed you this session (Job Cave, PKers), newest first, with the damage. Clear empties it. The bot's own targets, buffs, heals and resurrects are on the Log page as Attack: ....

Not in vSRO 1.188, shown greyed out: Mirror Reflect. The ground-cast packet (teleport skills) is not confirmed on this server: watch the log the first time.

Protection NEW

Keeps the character alive and safe: potions and pills, returning to town, reviving, stat points and disconnect rules.

The page has four tabs: Potions (potions, pills, scrolls, stats), Return to town, Dead and pet (dead, pet return, misc) and Berserk and monsters.

Most rows are a switch and a number. The number is only used while the switch is on.

Potions and pills

Stats

Add stat points automatically spends free stat points by itself. Each level's 3 points chooses the split: 3 STR, 2 STR · 1 INT, 1 STR · 2 INT, or 3 INT. +1 STR and +1 INT add one point by hand.

Return to town

When a checked reason becomes true, NexBot stops what it is doing and uses a return scroll: any return scroll in the bag, an instant one first (not the bandit den scroll). Without a return scroll it only stops and writes a warning in the log. The reasons are checked while the bot is busy (walking a script, trading or, later, hunting) and, with Also check when not botting (outside towns) on, whenever you are outside a town. You count as in town when a shop NPC is near; after leaving town the checks wait 10 seconds. The log shows Protection: return-to-town checks on / paused.

Check now lists every return option that is on, its value right now and whether it would send you back ([RETURN]). "Not attacked" and "Every N minutes" count only while the checks are on.

Character

Town NEW

The town loop: sell junk, repair, buy potions and scrolls up to your amounts, then walk back to training.

How the town loop works

  1. Arrive in townProtection uses a return scroll, or you use one yourself in the game (or revive in town). With Run the town loop after returning to town on, the loop starts after the teleport. Run now starts it by hand.
  2. Walk the town scriptNexBot picks the town script with a point near the character, so one script per town is enough. With no script near the character, the town loop does not move: record one for each town you use.
  3. Visit the shops on the wayEvery shop NPC within about 30 m of the route that has something to do is visited. NexBot sells first, then repairs (blacksmith / armor shop), then buys.
  4. Walk to trainingWhen the town script ends, the training script is walked, if one is set. Loop the training script keeps walking it.

Recording a town script

Use the Script page. Use a return scroll, then press ● Record and walk from where you appear, past the potion seller, the blacksmith and the grocery, to the town gate. Save it, for example as Jangan town.txt, and add it with Add…. Record the walk from the gate to your training spot as a second script and set it under Then walk to training.

You don't need BUY or SELL lines in the town script. Walking close to the NPCs is enough, and the town loop does the shopping from the buy list.

Buy list

Type part of an item name and press Search (or Enter). All lists everything any NPC sells, Mine shows your list, and Reset clears it. Tick On and type Keep: how many to have after buying. What is already in the bag counts, so with Keep 200 and 30 potions in the bag, 170 are bought.

Character

Inventory

Equipment, avatar and bag, with icons and item details, and the exchange window, even when clientless.

  • Move: drag an item onto another slot, including equipment and avatar slots.
  • Use / wear: right-click or double-click to use potions and scrolls, wear equipment or take it off.
  • Details: point at an item and a card like the game's opens at the mouse: name, sort of item and level, the item's description (for example A bag of 1,000 potions that can heal 570 HP pts. each.), magic options, durability and quantity. With a database built with this version (Server, Build database) it also shows the game's How To Use and Restriction parts and values such as MP recovery[820], and items bought in the item mall appear in the bag right away.
  • 3D view: in game, the 3D view button under the equipment opens your character's 3D model from the game client. Drag to turn it, use the mouse wheel to zoom and double-click to reset. Your character stands and plays the game's own idle animation, wearing your armor and avatar, with your weapon in hand (in its stance) and your shield on the arm. It changes when you change equipment.
  • Animated slots: like in the game, the scroll of a pet that is summoned now glows on and off, and rare items (Seal of Star, Moon, Sun) have a light circling the slot.
  • Equipment cards: worn items, avatar items and equipment in the bag get the game's full card: sort of item, mounting part and degree (orange), the white stats with how well each one rolled (for example Phy. def. pwr. 2.2 (+0%), Durability 40/44 (+0%), attack, parry, block, reinforce, absorption), the magic options (blue), then required level, gender, race, Max No. of magic options and Able to use Advanced elixir. The stats need a database built with this version.
  • Character card: between the equipment slots you see your character's face portrait from the game in a gold frame, your name, level and race, and your main stats (attack, defense, hit rate, parry, STR / INT). The Character page shows the same portrait next to your name. Not in game, a crest is shown instead.
  • Split a stack: hold Shift while you drag a stack onto an empty slot (or onto the same item). A window asks how many to move (1, Half, All but 1, or type a number).
  • Global message: right-click a global chatting item, or click Global under the bag. Write the message (up to 100 characters) and press Send; one item is used.
  • Auto sort: stacks matching items and orders the bag. Stop cancels it.
  • Refresh: reads the inventory and equipment again at once and retries item pictures that did not load.

Exchange

The right panel is the game's exchange window. It works clientless too, and with the game open it shows the same exchange as the game's window.

  1. StartPick a player in Player nearby and click Exchange. When someone asks you, Accept and Refuse show instead (for 30 seconds), and the log says who asked.
  2. Put items and gold inDrag items from the bag onto Your items (the whole stack goes in; split it first for less). Or Alt + click a bag item: it goes into the next empty exchange slot. Attribute (white stones)

Select an item and an attribute stone, then set Stop at white %. The line stops when the stat reaches that percent. Add all stones queues every matching stone for the item. White % is read for the weapon, armor, shield and accessory stats the bot knows. For other stones it stops after one success.

Servers can use different alchemy packet types. The line at the bottom of the queue (e.g. elixir 3 · stone 4 · attribute 5) shows what NexBot uses. Fuse one item yourself in the game client, and NexBot learns your server's values.

Troubleshooting

Common problems and how to fix them.

The map is empty

Select the client folder on Server and click Read server config. The minimap pictures come from the client.

Items or skills show no names or icons

Click Build database on the Server page. Build it again after a client update.

The stall refuses items (error 0x3C2A)

Open a stall in the game client and add one item yourself. NexBot learns the layout (see Stall).

Lucky powder is not used

  • Make sure the Lucky powder box is checked and the item is at the at + value or higher.
  • The powder's degree must match: Auto uses the item's degree. If your server's powders have other degrees, pick the degree yourself.
  • The log warns “no lucky powder of degree N in the inventory” when it can't find one.

Alchemy does nothing / the server refuses

Fuse one item yourself in the game client, so NexBot learns your server's alchemy packet types (see Alchemy).

A new feature isn't in the window

NexBot must be closed while it is rebuilt. If it was open, you are still running the previous version.
